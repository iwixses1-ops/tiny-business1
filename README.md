# Tiny Business 🏪

Бизнес-симулятор / idle-игра для Telegram. Игрок начинает с палатки с
лимонадом, зарабатывает виртуальные монеты, открывает магазины, кафе,
пиццерии, супермаркеты и отели, нанимает сотрудников, выполняет задания и
открывает достижения.

Проект поддерживает два режима:

- **Mini App** (основной): красивая веб-игра внутри Telegram, открывается по
  кнопке «🚀 Играть». Требует HTTPS-адрес.
- **Игра в чате**: те же действия доступны кнопками прямо в переписке с ботом —
  работает даже без Mini App.

Рекомендуемый бесплатный хостинг: **Bothost.ru** (даёт HTTPS-домен автоматически).

## Архитектура

```
        Telegram
           │
   ┌───────┴────────┐
   │                │
   ▼                ▼
┌──────────┐   ┌─────────────────────────┐
│ Бот      │   │ FastAPI (backend/main.py)│
│ aiogram  │   │  • /api/* игровой API    │
│ кнопка   │   │  • раздаёт frontend      │
│ «Играть» │◀──│  (index.html, app.js)    │
└──────────┘   └───────────┬─────────────┘
                           │ проверка initData (auth.py)
                           ▼
                    ┌─────────────┐
                    │ SQLite      │
                    │ data/*.db   │
                    └─────────────┘
```

- **bot/** — Telegram-бот: показывает кнопку Mini App, а также даёт играть
  прямо в чате кнопками.
- **backend/** — FastAPI: игровой API + раздача frontend. Единственный
  источник истины (деньги, доход, уровни, задания считаются только тут).
- **frontend/** — интерфейс Mini App (HTML/CSS/JS, Telegram WebApp SDK).
- **SQLite** — хранение прогресса.

## Что и как работает

**Экономика** (`backend/economy.py`) — единственное место с ценами.

| Предприятие | Цена | Доход/мин |
|---|---|---|
| 🥤 Палатка с лимонадом | бесплатно | 2 |
| 🏪 Продуктовый магазин | 300 | 12 |
| ☕ Кафе | 1000 | 35 |
| 🍕 Пиццерия | 5000 | 120 |
| 🛒 Супермаркет | 20000 | 400 |
| 🏨 Отель | 100000 | 1800 |

Сотрудники: Продавец (+10% к лимонаду, 200), Повар (+15% к кафе, 1000),
Менеджер (+10% ко всему, 5000), Директор (+15% ко всему, 25000).

**Офлайн-доход**: сервер начисляет его по времени последнего действия,
ограничен 8 часами. Клиент не может передать произвольную сумму.

**Безопасность**: подпись Telegram initData проверяется HMAC-SHA256,
проверяется `auth_date`; в проде локальный тест запрещён
(`PUBLIC_DEPLOYMENT=true`).

## Установка на Windows

### 1. Установи Python 3.12

С https://www.python.org/downloads/windows/ , галочка **«Add Python to PATH»**.
Проверь: `python --version`.

### 2. Виртуальное окружение

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Зависимости

```powershell
pip install -r requirements.txt
```

### 4. Файл .env

```powershell
Copy-Item .env.example .env
```
Впиши `BOT_TOKEN` и (для теста Mini App) `WEBAPP_URL`.

## Настройка Telegram-бота

1. **@BotFather** → `/newbot` → скопируй token.
2. Вставь в `.env` → `BOT_TOKEN=...`.

## Запуск

Сервер + бот одной командой:
```powershell
.\.venv\Scripts\python run.py
```
Только бот: `python run.py --bot`
Только сервер: `python run.py --server`

Для локального теста Mini App в браузере: открой `http://127.0.0.1:8080`
(при `ALLOW_LOCAL_TEST=true` авторизация пропускается).

## Деплой на Bothost (Mini App)

Bothost сам выдаёт HTTPS-домен и SSL — именно то, что нужно Mini App.

### Шаг 1. Загрузи код на GitHub

1. Создай репозиторий на github.com (например `tiny-business`).
2. **Add file → Upload files** и загрузи **всё содержимое** папки проекта
   так, чтобы `run.py` лежал **в корне** репозитория.
   ⚠️ `.env` НЕ загружай (секрет).
3. **Commit changes** → скопируй URL (`Code → HTTPS`).

### Шаг 2. Создай бота на Bothost

Заполняй форму так:

| Поле | Значение |
|---|---|
| Название бота | `tiny-business` (любое) |
| Платформа | **Telegram** |
| Язык разработки | **Python** |
| Версия Python | **3.11 (рекомендуется)** |
| Bot Token | твой токен от BotFather |
| Локация | Россия (Москва) |
| **Использовать домен** | **✅ ВКЛЮЧИТЬ** (нужно для Mini App) |
| Git URL | `https://github.com/твой_логин/tiny-business.git` |
| Ветка | `main` |
| **Главный файл** | **`run.py`** |
| Собственный Dockerfile | выключено |

### Шаг 3. Переменные окружения

В форме (или позже в настройках бота) добавь:

| Ключ | Значение |
|---|---|
| `PUBLIC_DEPLOYMENT` | `true` |
| `ALLOW_LOCAL_TEST` | `false` |
| `WEBAPP_URL` | `https://<выданный-домен>` — **узнаешь после первого запуска** |
| `CORS_ORIGINS` | `*` |

### Шаг 4. Запусти и подставь домен

1. Нажми **Start**. В логах появится выданный домен вида
   `https://bot1234.bothost.tech`.
2. Впиши его в переменную `WEBAPP_URL` и **перезапусти**.
3. В Telegram напиши боту `/start` → появится кнопка **«🚀 Играть (Mini App)»**.

### Шаг 5 (по желанию). Кнопка меню в BotFather

В **@BotFather** → `/mybots` → выбери бота → **Bot Settings → Menu Button** →
укажи URL `https://bot1234.bothost.tech`. Тогда Mini App откроется и из меню
слева от поля ввода.

> **Про данные:** на бесплатном тарифе файловая система может сбрасываться
> при пересборках — прогресс обнулится. Для постоянного хранения возьми
> платный тариф с диском.

## Админ-панель

Админ-панель встроена в Mini App и **видна только администраторам**. Доступ
определяется списком `ADMIN_IDS` в переменных окружения.

### Как включить

1. Узнай свой Telegram ID (например, у бота **@userinfobot**).
2. Добавь переменную окружения: `ADMIN_IDS=<твой_id>` (несколько — через запятую).
3. Перезапусти. В Mini App появится вкладка **🛠 Админ**.

### Что умеет

- **Статистика игры**: игроков, забанено, монет в игре, предприятий.
- **Поиск игроков** по ID или имени.
- **Выдача ресурсов** любому игроку:
  - `+1000 🪙` — добавить монеты;
  - `Выдать ВСЁ` — все предприятия (ур. 10), все сотрудники, 1 000 000 монет;
  - `Открыть всё` — все предприятия и сотрудники.
- **Бан / разбан** игрока с указанием причины. Забаненный не может играть:
  Mini App отдаёт ему 403, а бот отвечает «Вы забанены».
- **Сброс прогресса** игрока к стартовому состоянию.

### Как это защищено

- Права проверяются на сервере по `ADMIN_IDS` — клиент не может «прикинуться»
  админом.
- Админ-маршруты (`/api/admin/*`) доступны только админам (иначе 403).
- Забанить или сбросить администратора нельзя.
- Список админов не отдаётся клиенту (наружу уходит только флаг «ты админ»).

### В боте

Команда `/admin` показывает краткую сводку (только админам). Полное
управление — в Mini App.

## Донат-магазин

В Mini App есть вкладка **🛍️ Донат** с необязательными цифровыми товарами:

- **Монеты** — стартовый (50 000, 1 ₽), бизнес-пакет (250 000, 3 ₽), казна (1 000 000, 7 ₽).
- **Премиум** — временной множитель дохода **×1.5**: на 1 день (3 ₽), 7 дней (15 ₽), 30 дней (50 ₽).

Цены и описания легко менять в `backend/shop.py` (список `SERVICES`).

**Поток (полностью на автомате):**
1. Клиент жмёт «Купить» → создаётся **заявка** (`orders`).
2. В Mini App открывается (или даётся ссылка на) **владельца** — клиент пишет ему номер заявки и оплачивает.
3. Заявка появляется в админ-панели (вкладка **🧾 Заявки**) со статусом «⏳ ожидает».
4. Владелец нажимает **«💰 Подтвердить оплату»** → награда **выдаётся автоматически** (монеты зачисляются / премиум включается).
   Повторное подтверждение невозможно — двойной выдачи нет.
5. Если оплаты не было — владелец нажимает «Отклонить».

### Как настроить приём оплаты

В переменных окружения укажи владельца (на него переходят клиенты платить):
- `OWNER_USERNAME=твой_юзернейм` (без `@`) — ссылка `t.me/твой_юзернейм`;
- или `OWNER_ID=123456789`.

> Правила: это продажа цифровых игровых товаров. Никакого казино, ставок,
> случайных выигрышей и вывода игровых монет в реальные деньги нет.
> Покупка не обязательна для прохождения.

## Рассылка для админов

Админ может разослать сообщение **всем игрокам** — в админ-панели вкладка
**📣 Рассылка**. Вводишь текст → жмёшь «Отправить» → фоновый воркер бота
рассылает его по очереди (с паузой, чтобы не словить лимиты Telegram).

- Забаненные игроки пропускаются.
- Кому уже отправили — хранится в БД, поэтому после перезапуска дублей нет.
- Твоя рассылка видна в истории со счётчиками «отправлено / ошибок».

Настройки скорости: `BROADCAST_DELAY_SEC` (задержка между сообщениями) и
`BROADCAST_RATE_PER_MIN` (запасной лимит).

## Диагностика ошибок

| Ошибка | Причина | Решение |
|---|---|---|
| Бот не отвечает | неверный `BOT_TOKEN` | проверь токен в переменных |
| «Invalid initData signature» | `WEBAPP_URL`/токен не совпадают, или задан `ALLOW_LOCAL_TEST=true` | в проде: `PUBLIC_DEPLOYMENT=true`, `ALLOW_LOCAL_TEST=false`, токен = от BotFather |
| Mini App белый экран | `WEBAPP_URL` не HTTPS или сервер не поднялся | включи «Использовать домен», проверь логи |
| Кнопки нет в меню | `WEBAPP_URL` не начинается с `https://` | впиши выданный Bothost домен |
| `ModuleNotFoundError` | не установились зависимости | проверь, что `requirements.txt` в корне репозитория |
| Прогресс обнуляется | сброс диска на free-тарифе | платный тариф с постоянным диском |

## Ограничения первой версии

- Реферальная награда — после первого `/start` приглашённого.
- Офлайн-доход ограничен 8 часами.
- Сотрудники покупаются по одному разу каждого вида.
- Платежей нет (архитектура готова к Telegram Stars).
- На бесплатном хостинге нет гарантии сохранности SQLite.
